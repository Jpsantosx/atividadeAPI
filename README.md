# Consulta de Personagens Dragon Ball

Aplicação Flask que pesquisa personagens na Dragon Ball API e apresenta informações como raça, gênero, Ki, descrição e imagem.

## Funcionalidades

- Pesquisa de personagens por nome
- Consumo da Dragon Ball API
- Páginas personalizadas para erros 404 e 500

## Como executar

```bash
pip install -r requirements.txt
python app.py
```

Depois, acesse `http://localhost:5000`.
